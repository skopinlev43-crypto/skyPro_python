БАГ-РЕПОРТ №1: Метод capitalize() искажает регистр остальных букв в строке
--------------------------------------------------------------------------------
• Статус: Открыт
• Приоритет: Высокий (High)
• Краткое описание: Метод не просто делает первую букву заглавной (как заявлено в документации), 
                    а принудительно переводит все остальные буквы строки в нижний регистр.
• Шаги для воспроизведения:
  1. Вызвать метод: utils.capitalize("SKYPRO")
• Ожидаемый результат: "SKYPRO" (первая буква заглавная, остальные не меняются)
• Фактический результат: "Skypro" (остальные буквы принудительно стали строчными)
• Комментарий для разработчика: Встроенный метод Python `string.capitalize()` работает именно так — 
  он опускает регистр всех символов, кроме первого. Если требуется изменить только первую букву, 
  нужно использовать срез: `string[0].upper() + string[1:]` (с обработкой пустых строк).

БАГ-РЕПОРТ №2: Метод contains() неверно обрабатывает поиск пустой подстроки ""
--------------------------------------------------------------------------------
• Статус: Открыт
• Приоритет: Средний (Medium)
• Краткое описание: При передаче пустой строки `""` в качестве искомого символа, метод возвращает `False`. 
                    В Python любая строка считается содержащей пустую строку, стандартный оператор `in` возвращает `True`.
• Шаги для воспроизведения:
  1. Вызвать метод: utils.contains("SkyPro", "")
• Ожидаемый результат: `True`
• Фактический результат: `False`
• Комментарий для разработчика: Логика `string.index("")` возвращает `0`. Проверка `0 > -1` дает `True`. 
  Однако из-за дефекта в коде или некорректной обработки исключений логика ломается. 
  Рекомендуется заменить конструкцию `try-except` и метод `.index()` на более идиоматичный и безопасный оператор `in`: 
  `return symbol in string`.

БАГ-РЕПОРТ №3: КРИТИЧЕСКИЙ: Метод delete_symbol() полностью очищает строку при удалении подстроки ""
--------------------------------------------------------------------------------
• Статус: Открыт
• Приоритет: Критический (Critical) / Блокирующий для бизнес-логики
• Краткое описание: Если в метод передать пустую строку `""` в качестве символа для удаления, 
                    он полностью уничтожает исходный текст и возвращает пустую строку `""`, вместо того 
                    чтобы вернуть строку без изменений.
• Шаги для воспроизведения:
  1. Вызвать метод: utils.delete_symbol("SkyPro", "")
• Ожидаемый результат: "SkyPro"
• Фактический результат: ""
• Комментарий для разработчика: Это следствие багов в методах `contains` и `replace`. 
  В Python `"SkyPro".replace("", "")` возвращает исходную строку. Но если `contains` по ошибке вернет `True`, 
  а логика завязана на некорректные замены, метод затирает данные. Требуется добавить валидацию: 
  `if not symbol: return string`.
